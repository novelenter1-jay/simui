심의일정 엑셀 업로드

평소 쓰시는 심의일정 엑셀(한셀 저장본 그대로)을 끌어다 놓으면 됩니다. 월 시트를 자동 인식하고, 학교 칸의 전화번호는 자동 제거됩니다. 같은 심의번호는 갱신되며 위원들이 이미 체크한 출석 정보는 지워지지 않습니다.
여기에 엑셀 파일을 끌어다 놓거나 클릭하여 선택
반영할 월을 선택하세요 (기본: 이번 달부터)
게시 시 선택 월의 기존 등록분 중 이번 파일에 없는 건은 삭제 여부를 물어봅니다. 미리보기의 학교 표기 칸은 클릭해 수정할 수 있습니다.

소위별 위원 명단 업로드

「소위원회 구성」 엑셀을 끌어다 놓으세요. 성명·위원구분·간사·요일만 저장되며 연락처와 이메일은 서버에 올라가지 않습니다. 명단이 바뀌면 새 파일을 다시 올리면 됩니다.
여기에 구성 엑셀 파일을 끌어다 놓거나 클릭하여 선택

소위별 접속 코드

위원들이 입력할 소위별 코드입니다. 서버에는 암호화(해시)된 값만 저장되므로, 아래 평문 코드는 이 브라우저에만 보관됩니다. 저장 후 코드 목록을 복사해 안전한 곳에 따로 보관하세요.
